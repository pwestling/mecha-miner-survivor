# Technical Decision Log

Technical decision records preserve consequential architectural choices and their rationale. Current normative behavior remains in the technical subsystem documents; these records explain why it was selected.

## Record format

Each `TDR-###-short-name.md` contains:

1. Decision and status.
2. Context and constraints.
3. Considered alternatives.
4. Rationale.
5. Consequences and risks.
6. Validation and reversal signals.
7. Specification links.
8. Supersession history when applicable.
